# Automation Logs

This folder stores execution logs generated by the automation framework.

## Purpose
Keep automation run history and diagnostic information in one place for troubleshooting and audit review.

## Contents
- Validation logs
- Provisioning logs
- Error logs
- Report export logs

## Notes
- Logs may be excluded from version control if they contain sensitive or environment-specific data.
- Use clear filenames and timestamps for log retention and cleanup.
