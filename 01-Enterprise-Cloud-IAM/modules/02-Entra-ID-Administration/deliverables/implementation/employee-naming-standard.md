# Employee Naming Standard

This document defines naming conventions used for employee identities.

- Employee ID: `MI-XXXX` (four-digit sequential number)
- Display name: `Firstname Lastname`
- User Principal Name (UPN): `firstname.lastname@daveshub.onmicrosoft.com`
  - Lowercase, dot separator, no diacritics
- Mail nickname / alias: `firstname.lastname`

Examples:
- Employee ID: `MI-0001`
- Display Name: `Jane Doe`
- UPN: `jane.doe@daveshub.onmicrosoft.com`

Validation rules:
- No special characters in UPN local part besides `.`
- Firstname/Lastname fields must be title-cased in display name
- Employee ID must be unique
