# HR Data Management

This folder contains HR-related data and templates used for identity provisioning.

## Purpose
Store HR source files, onboarding and offboarding artifacts, employee records, and provisioning templates.

## Subfolders
- `employees/` — employee-specific documentation or records
- `onboarding/` — onboarding forms and checklists
- `offboarding/` — offboarding processes and templates
- `processed/` — processed HR exports for provisioning
- `source/` — source HR data files used for provisioning
- `templates/` — reusable forms, templates, and CSV schemas
- `archive/` — archived HR data and retired artifacts

## Notes
- Keep source HR data in `source/` and processed provisioning data in `processed/`.
- Do not store sensitive employee information in version control unless approved.
