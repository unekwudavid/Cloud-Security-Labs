# Microsoft Graph Automation

This folder contains automation scripts and helpers that use Microsoft Graph to manage identity resources.

## Purpose
Use Microsoft Graph to perform tasks that may be more efficient or better supported via Graph API than with native PowerShell cmdlets.

## Typical use cases
- User lifecycle management
- Security group management
- License allocation
- Reporting and analytics
- Identity Governance tasks

## Notes
- Ensure Graph authentication and permissions are configured before running scripts.
- Prefer Graph-based automation for modern Microsoft Entra ID workflows.
- Store reusable Graph query patterns and helper functions here.
