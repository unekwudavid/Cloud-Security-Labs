# Project 2 — Identity Federation & Zero Trust Platform

## Project Purpose

This project extends the Enterprise Identity Platform developed in Project 1 into the application and authentication layer.

The platform demonstrates how workforce identities in Microsoft Entra ID can securely access enterprise applications through modern authentication, federation, automated provisioning, and Zero Trust controls.

## Business Context

The project simulates identity and application security requirements for Mustard Innovations, a fictional enterprise organization.

The environment represents a workforce identity provider responsible for securely integrating employees with internal and SaaS applications.

## Primary Objectives

- Implement enterprise application integration
- Demonstrate SAML 2.0 federation
- Demonstrate OAuth 2.0 authorization
- Implement OpenID Connect authentication
- Implement SCIM application provisioning
- Demonstrate Conditional Access and MFA
- Implement identity risk controls
- Demonstrate IAM monitoring and troubleshooting
- Integrate multiple identity providers
- Implement Zero Trust application access
- Automate identity infrastructure using Terraform
- Integrate IAM configuration into CI/CD workflows

## Project Principles

- Zero Trust
- Least Privilege
- Strong Authentication
- Identity-Centric Security
- Automated Provisioning
- Continuous Verification
- Secure Application Integration
- Infrastructure as Code
- Auditability
- Fail-Safe / Fail-Closed Design
