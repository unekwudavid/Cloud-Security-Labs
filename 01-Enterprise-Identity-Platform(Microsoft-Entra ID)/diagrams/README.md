# Enterprise Architecture Diagrams

This folder contains the architecture diagrams supporting the Mustard Innovations Enterprise Cloud IAM implementation.

These diagrams provide a visual representation of the identity platform, automation workflows, governance model, and security controls implemented throughout the project.

## Included

- Enterprise Identity Architecture
- User Provisioning Workflow
- Role-Based Access Control (RBAC) Model
- Conditional Access Architecture
- Joiner–Mover–Leaver (JML) Lifecycle
- Automation Components

The diagrams are created using Draw.io and exported as PNG images for easy review.
